
# Controle Parental Alice - Caminho 2 - Grátis pelo iPhone

Esse projeto você cria 100% pelo iPhone 11 sem Android Studio.

O que faz:
- Launcher infantil que mostra só os Mundos da Alice
- Bloqueia acesso a Roblox até terminar tarefas 1 a 4 com foto
- Libera 40 min de Roblox até 18:30 para proteger sono
- Timer regressivo dentro do app
- Localização transparente com notificação permanente

Como usar só com iPhone 11:
1. Crie uma conta no GitHub pelo Safari
2. Crie repositório novo e faça upload desses arquivos
3. O GitHub Actions vai compilar o APK sozinho (aba Actions)
4. Baixe o APK gerado e envie para o Android da Alice via WhatsApp ou Drive
5. No Android da Alice, permita instalar apps desconhecidos e instale

Sem custo, sem Android Studio.
