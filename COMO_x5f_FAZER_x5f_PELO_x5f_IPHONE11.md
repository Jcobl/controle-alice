
# Como fazer tudo pelo iPhone 11 - Passo a passo

1. No Safari do iPhone 11, crie conta no github.com
2. Crie repositório novo chamado controle-alice
3. Clique em Add file > Upload files e envie todos arquivos dessa pasta
4. Vá em Actions > vai ver workflow Build APK Alice rodando
5. Quando ficar verde, clique nele > Artifacts > baixe app-alice-release
6. Envie esse APK por WhatsApp para o Android da Alice
7. No Android da Alice, ative instalar apps desconhecidos e instale
8. Defina como launcher padrão quando pedir

Para localização transparente:
- O app já mostra notificação permanente "Localização compartilhada com família - Alice pode ver"
- Isso é exigido por lei LGPD e mostra para ela que está sendo acompanhada

Tempo Roblox:
- Código já limita 40 min e termina 18:30
- Quando acaba, bloqueia e mostra tela de banho e história
